## Что такое Табрика

[Табрика](https://tabrica.ru) — конструктор баз данных и таблиц без кода: хранение данных, командная работа и автоматизация через Public API. Этот пакет подключает API Табрики к [n8n](https://n8n.io), и ваши таблицы можно использовать в любых сценариях без программирования.

## Установка

### Через интерфейс n8n (self-hosted)

1. Откройте **Settings → Community Nodes**.
2. Нажмите **Install** и введите `n8n-nodes-tabrica`.
3. Подтвердите уведомление о community-нодах и нажмите **Install**.

### Из командной строки

```bash
cd ~/.n8n/nodes
npm install n8n-nodes-tabrica
```

После установки перезапустите n8n. Нужен Node.js 18.10 или новее.

## Подключение

1. В Табрике откройте настройки организации → вкладка **API** и создайте токен.
   - Токен **на чтение**: получение списка и одной записи.
   - Токен **на запись**: дополнительно создание, изменение и удаление.
2. В n8n создайте креды **Tabrica API**:

| Поле | Значение |
| --- | --- |
| Base URL | `https://api.tabrica.ru` (или адрес вашей установки) |
| API Token | токен из шага 1 |

## Возможности

### Нода Tabrica — записи

| Операция | Что делает |
| --- | --- |
| **Get Many** | Список записей: пагинация, фильтры, сортировка, выбор полей, формат форматированного текста. *Return All* сам проходит по всем страницам. |
| **Get** | Одна запись по ID. |
| **Create** | Создание записи, при желании возвращает полную запись. |
| **Update** | Частичное обновление записи. |
| **Create or Update** | Ищет запись по полю (например, по email), обновляет её или создаёт новую. В ответе есть `_action`: `created` или `updated`. |
| **Delete** | Удаление записи. |
| **Count** | Количество записей в таблице, в том числе по фильтру. |

### Удобство

- 🔗 **Ссылка на таблицу.** Вставьте адрес таблицы из браузера, ID базы и таблицы подставятся сами.
- 🧩 **Три способа передать данные:** список «поле — значение» с типами, JSON или автоматический маппинг входящего item.
- 🔍 **Визуальные фильтры.** Условия «равно», «содержит», «больше», «между», «в списке», «пусто» и другие, с логикой И / ИЛИ. Работают ключевые слова дат: `today`, `daysAgo,7`. Сырой `where` тоже доступен.
- ↕️ **Правила сортировки** по возрастанию и убыванию, в том числе по `id` и `created_at`.
- 🎯 **Только нужные поля** — ответы меньше и быстрее.
- 💬 **Понятные ошибки** с подсказками: «токен только на чтение», «запись не найдена» и другие.
- 🤖 **Работает как инструмент AI Agent** в n8n.
- ♻️ **Совместимость** с воркфлоу, созданными на версии 0.1.x.

### Tabrica Trigger

Запускает сценарий, когда в таблице появляется **новая запись**. Можно ограничить фильтром. Записи приходят от старых к новым. Первая активация только запоминает текущее состояние, поэтому старые строки не придут лавиной.

## Пример: заявки с формы в Табрику

```
Webhook  ──►  Tabrica (Create or Update)  ──►  Telegram
              Match Field: Email
```

1. Добавьте триггер **Webhook** для вашей формы.
2. Добавьте ноду **Tabrica**, выберите **Create or Update** и вставьте ссылку на таблицу.
3. В *Data Mode* выберите **Map Input Data Automatically** или заполните поля вручную, а в *Match Field* укажите `Email`.
4. Ветвитесь по `{{ $json._action }}`, чтобы уведомлять только о новых клиентах.

## Важно знать

- Каждый входящий item — это один запрос к API, и он учитывается в месячном лимите Public API вашего тарифа. Выбирайте нужные поля и используйте *Return All* с большим размером страницы.
- ID можно взять из адреса таблицы: `https://tabrica.ru/orgs/<организация>/db/<id-базы>/table/<id-таблицы>`.
- В Public API пока нет методов, которые отдают списки баз, таблиц и полей, поэтому они задаются ссылкой или ID, а не выбираются из выпадающих списков.
